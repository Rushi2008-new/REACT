# React Learning Journey

Welcome to my React practice workspace — a curated collection of mini-projects built with React and Vite to strengthen core frontend concepts through hands-on learning.

This repository is more than just a set of apps; it is a step-by-step journey through the fundamentals of React, from basic state and components to context, routing, and local persistence.

## ✨ What this project represents

These projects were built to explore and practice:

- React components and JSX
- State and event handling
- Hooks such as useState, useEffect, and useRef
- Context API for shared state
- React Router for navigation
- Local storage for persistent data
- Tailwind CSS for modern UI styling
- Vite as a fast development environment

## 🧠 Project overview

Each folder represents a small learning milestone:

- 02Counter — a beginner-friendly counter app to understand state updates
- 04bgchanger — a background color changer using React state
- 05passwordGenerator — a password generator with customization options
- 07reactRouter — a multi-page app using React Router
- 08miniContext — a simple app showcasing Context API usage
- 09themeswitcher — a dynamic theme switcher built with context
- 10todocontextLocal — a todo app with context management and local storage
- Fundamentals — core React basics and practice exercises
- customReact — a hands-on attempt to understand React internals more deeply

## 🛠️ Tech stack

- React 19
- Vite
- JavaScript / JSX
- Tailwind CSS
- React Router DOM
- ESLint

## 🚀 How to run any project

Each project is a standalone Vite app. To run one locally:

```bash
cd <project-folder>
npm install
npm run dev
```

Example:

```bash
cd 05passwordGenerator
npm install
npm run dev
```

## 📚 Learning path

A good progression through this workspace would be:

1. Start with the basics in Fundamentals and 02Counter
2. Move into interactive UI apps like 04bgchanger and 05passwordGenerator
3. Learn state sharing with 08miniContext and 09themeswitcher
4. Build more structured apps with 07reactRouter and 10todocontextLocal
5. Explore deeper React concepts in customReact
